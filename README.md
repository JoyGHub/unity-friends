## 📖 About

This repository is based on Unity Technologies' official Friends Sample project.

The goal of this fork is to transform the sample into something that feels closer to what you'd expect from a production-ready social system by improving both functionality and user experience.

> **Original Repository**
>
> https://github.com/Unity-Technologies/com.unity.services.samples.friends
